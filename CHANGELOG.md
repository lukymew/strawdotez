# Changelog

All notable changes to this project are documented here.
Format based on [Keep a Changelog](https://keepachangelog.com/).

## [Unreleased]

### Added
- `straw config`: menu and commands (`list`, `get`, `set`) to change language, default shell, font, device profile, banner, welcome message, name and e-mail, then apply.
- Default shell choice (bash or zsh) in the installer and in `straw config`.
- Font choice: JetBrains Mono, Fira Code, Hack and Meslo (Nerd Fonts), pinned by tag and sha256.
- Release binaries now carry a build provenance attestation: `gh attestation verify straw-ui-linux-arm64 --repo lukymew/strawdotez`.
- Tests for the `straw-ui` download in `install.sh` (good checksum, bad checksum, missing files) and for `command_not_found`.
- `docs/TROUBLESHOOTING.md` (English and Portuguese), `CONTRIBUTING.md` and issue and PR templates.

### Fixed
- zsh `command_not_found` now gives the same hints as bash (one shared template).
- The Alpine `php` package is now `php83` (there is no plain `php`).

## [1.3.0] - 2026-11-25

### Added
- `straw tools`: interactive tool browser written in Go with the standard library only (live search, mark several, install, resizes with the screen, restores the terminal on failure). With a search term it just lists the matches.
- `install.sh --version vX.Y.Z` (or `STRAW_VERSION`) installs a pinned release and downloads `straw-ui` from the same release.
- `SECURITY.md` (English and Portuguese): secrets policy, what the setup changes on the device, how to check the installer and how to report a vulnerability. The release also publishes `install.sh` and its sha256.
- `docs/REVIEW.md`: code review with 21 findings and what was fixed.
- `tests/functions.bats` (15 tests for the shell functions) and 13 tests for `straw`, all run in CI.
- `scripts/setup-dev.sh` (turns on the pre-commit hook) and `.chezmoidata/ui.yaml` (`banner_title` for the header).
- `check-i18n.py` now checks that `%s`/`%d` match between pt and en and bans `$` and backticks in `straw_*` messages; `ci-check.sh` validates `straw.json` and cleans up after itself.

### Changed
- `allow-external-apps` is now off by default in `termux.properties`.
- zsh plugins are pinned to a version with a sha256 checksum instead of following the main branch.
- GitHub Actions are pinned by commit hash.
- `LANG` follows the language chosen at install (`pt_BR.UTF-8` or `en_US.UTF-8`).
- `HISTCONTROL=ignoreboth` in bash (commands starting with a space are not saved), like zsh.
- `setopt CORRECT` removed from zsh.
- `llm` and `llm-server` use the Termux `llama-cpp` package when present, or the binaries in `~/llama-bin`, and no longer export `LD_LIBRARY_PATH`.
- `battery`, `wifi`, `ports`, `listen` and `tb` tell you which package to install when it is missing; `timer` works without `termux-notification`.
- Before overwriting `termux.properties`, your edits are saved to `termux.properties.bak`.
- A package only counts as installed when dpkg says `install ok installed`.

### Fixed
- `genpasswd` and `genpin` no longer print "Broken pipe" when SIGPIPE is ignored (it broke the tests in CI).
- `clone` uses `--` before the URL; `rsfile` treats the search text literally.
- `@ip-locator` and `whatismyip` use HTTPS.

### Removed
- Dangerous aliases `rmrf` and `iptablesflush`, and `cve` (`searchsploit` does not exist in Termux).

## [1.2.0] - 2026-11-25

### Added
- `straw` command: `straw menu` (tools by module and tool profiles, with fzf), `straw update`, `straw version`, `straw help`.
- Modules and profiles in `.chezmoidata/straw.yaml`, with package lists per environment (Termux, Debian/Ubuntu/Kali, Alpine).
- Focused modules (C/C++, Go, Rust, web, network, pentest, privacy, media, editors) and more profiles (developer, networking, pentest, creator).
- Back button and quit in the menu; `straw install <package>` to install any package by name.
- Go part (`cmd/straw-ui`, `internal/`) that completes the bash `straw` without replacing it: `straw doctor` (environment, required tools, PATH and whether each module package exists in the package manager; exit code 1 on failures) and `straw tools [search]` (grouped, searchable list with installed marks).
- `straw.json`, generated by chezmoi with the language already resolved, is the data the Go part reads.
- Emojis in the menu (main menu, tool modules, profiles, back) with `STRAW_PLAIN=1` to turn them off; tool modules grouped as CLI, dev and network.
- "Search tools (Go)" entry in `straw menu`.
- CI job for Go (`gofmt`, `go vet`, `go test`).
- Release workflow: publishing a release builds `straw-ui` for arm64 and amd64 and attaches the binaries and `SHA256SUMS`.
- `install.sh` downloads `straw-ui` from the latest release and checks its sha256; if that fails it keeps going with bash only.

### Fixed
- Removed packages that do not exist in Termux (`hydra`, `sqlmap`, `mtr`) from the Termux lists.
- Menu opens with the first option on top (`--layout=reverse`) and a compact height.

## [1.1.0] - 2026-11-25

### Added
- GitHub Actions CI: renders every template in pt and en, checks syntax (`bash -n`, `zsh -n`, `shellcheck`) and runs the secret scan (gitleaks).
- `scripts/check-i18n.py`: checks that pt and en have the same messages.
- `scripts/bench.sh`: measures shell startup against a time budget.
- Pre-commit hook (`.githooks/pre-commit`) that blocks commits with tokens or private keys.
- `CHECKLIST.md`: what to update for each kind of change.

## [1.0.0] - 2026-11-25

First stable release.

### Added
- One-command install for Termux with chezmoi, safe to re-run.
- Install questions: language (pt/en), git name and email, phone/tablet profile, logo and header, Termux welcome message.
- bash and zsh sharing the same aliases and functions, with fzf and zoxide.
- Package list in `.chezmoidata/packages.yaml`, with a notice for packages that fail to install.
- One-line installer (`install.sh`) with a `--defaults` mode.
- Messages in Portuguese and English, with fallback when a translation is missing.
- README in English and Portuguese, with screenshots, and MIT license.
